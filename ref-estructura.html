Referência: estrutura de pastas do App Router (app/)

No Next.js com App Router, pasta é rota e arquivo é comportamento. Esta página é o mapa da cidade: cada pasta especial ([id], (grupo), @paralela, _privada) e cada arquivo (page.jsx, layout.jsx, loading.jsx…) tem um papel fixo. Consulte aqui quando a rota não abre ou o layout não aplica.

Você vai aprender
  • Arquivos de rota: page, layout, template, loading, error, not-found, route, default
  • Pastas especiais: [id] dinâmica, [...slug] catch-all, [[...slug]] opcional, (grupo) grupo de rota, @slot parallel route, _pasta privada
  • Onde ficam public/, next.config.js, .env*, middleware.js
  • Árvore exemplo comentada de um projeto real

A ideia: o mapa de um prédio onde o andar dá a rua

Pense na pasta app/ como um prédio: o nome do andar dá o endereço na rua (app/blog/page.jsx abre em /blog), e dentro de cada andar há arquivos com funções fixas — a portaria (layout.jsx, envolve tudo abaixo), a placa "aguarde" (loading.jsx), a página em si (page.jsx). Pastas entre colchetes viram endereços com número variável ([id]), entre parênteses não mudam a URL ((marketing)), com @ viram salas paralelas (renderizadas ao mesmo tempo) e com _ são salas técnicas (nunca viram rota).

Arquivos de rota (dentro de app/)

template.jsxComo o layout, mas remonta do zero a cada navegaçãoanimações de entrada por página

not-found.jsxPágina 404 do segmento (disparada por notFound())app/not-found.jsx global

Missão: a rota /sobre não abre porque o arquivo dentro de app/sobre/ está com o nome errado. No código, complete a constante com o nome certo do arquivo que torna a pasta uma rota: const ARQUIVO = 'page'. Rode para ver a "rota" aparecer. Depois clique em Verificar missão.

const ARQUIVO = '???'; // nome do arquivo que faz a pasta virar rota

function App() {
  const rota = ARQUIVO === 'page' ? '/sobre ✅ abre' : '/sobre ❌ 404';
  return (
    <div>
      <h1>📁 app/sobre/{ARQUIVO}.jsx</h1>
      <p>Resultado: {rota}</p>
    </div>
  );
}

Quando dá errado

Clássico: a rota não existe e o Next.js devolve 404 mesmo com a pasta criada. Quase sempre esqueceu o page.jsx dentro dela (pasta sem page não é rota) ou o arquivo está com extensão errada (page.js serve, Page.jsx com P maiúsculo não, em alguns sistemas):
404 — app/sobre/ existe mas não tem page.jsx
→ crie app/sobre/page.jsx (export default function …)
Outro clássico: o layout novo não envolve a página. Se o layout.jsx precisa receber {children} e você esqueceu, dá erro; e se pôs layout.jsx numa pasta (grupo), ele vale só para as rotas daquele grupo:
Error: layout.jsx must return {children} inside the JSX
→ return <html>…{children}…</html> no layout raiz
E a pasta privada: criar app/_utils/ e tentar acessar /_utils — não dá, porque o _ tira a pasta do roteamento (é só para código interno). O mesmo vale para (grupo): app/(marketing)/sobre/page.jsx abre em /sobre, não em /(marketing)/sobre.
