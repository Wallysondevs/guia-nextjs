Estrutura de pastas

A Ana abriu o projeto no VS Code e viu um monte de pastas: app, public, node_modules, um monte de arquivos com ponto na frente… "Qual deles eu mexo?" Nesta página você vai saber exatamente o que cada coisa faz e — o mais importante — onde escrever o código dela.

Você vai aprender
  • O que faz cada pasta: app/, public/, node_modules/, .next/
  • O que tem nos arquivos de configuração: package.json, next.config.mjs, .gitignore
  • Regra de ouro: onde colocar páginas, componentes, imagens e CSS
  • O que nunca deve ir para o git

A ideia: a planta da casa antes de pendurar os quadros

Antes de construir uma casa, o arquiteto entrega a planta baixa: um desenho mostrando onde fica a cozinha, onde fica o quarto, onde passam os canos. Ninguém constrói no escuro. Um projeto Next.js novo também chega com a planta pronta: cada pasta tem um cômodo específico. A pasta app/ é a área residencial — é lá que moram as suas páginas e componentes. A public/ é a vitrine da loja: tudo que está lá dentro fica disponível publicamente numa URL direta (uma imagem em public/foto.png vira /foto.png no site). A node_modules/ é o depósito das peças baixadas pelo npm — você não mexe there, só o npm mexe. E a .next/ é o canteiro de obras: o servidor de desenvolvimento compila seu código lá dentro; ela é recriada sozinha, então nunca deve ser commitada.

Os arquivos com ponto na frente (arquivos ocultos) são as "instalações da casa": .gitignore é a lista do que o git deve ignorar (justamente node_modules/ e .next/ — imagine commitar 300MB de dependências!), e package.json é a nota fiscal do projeto: lista os scripts (dev, build, start) e as dependências com suas versões. O next.config.mjs é o manual de ajustes finos do framework — no começo a Ana não precisa mexer nele.

Quando dá errado

Erro: a Ana criou a página dela como meu-app/pagina.jsx (na raiz, fora de app/) e o navegador mostra 404:
404 — This page could not be found.

Dica do guia: no App Router, só arquivos DENTRO da pasta app/ viram rotas
(pagina.jsx precisa estar em app/ — e para ser rota, precisa se chamar
page.jsx dentro de uma pasta: app/pagina/page.jsx = rota /pagina).
Erro: a Ana colocou a foto dela em app/foto.png e tentou usar /foto.png:
GET /foto.png 404 (Not Found)

Dica do guia: arquivos servidos direto precisam estar em public/.
app/ é só para código de rotas. Mova a imagem para public/foto.png.
